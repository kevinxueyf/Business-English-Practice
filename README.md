# 🎙️ BizPulse AI - 进阶式商务英语口语与听力实战闭环系统

> **以“进阶式实战 + 多维AI反馈”为核心壁垒，构建“听 (Listen) - 练 (Practice) - 说 (Speak) - 评 (Coach)”的完整闭环。**  
> 技术架构：**React 19 + TypeScript + Vite + Tailwind CSS + Google Gemini 多模态 API + Web Speech API (ASR / TTS)**

---

## 🌟 核心产品特色

1. **AI 驱动的动态听力模块 (Listening Comprehension)**
   - **多维度题型生成**：
     - **细节捕获**：填空题（抓取核心交付节点、违约赔偿金额、SLA 指标等）。
     - **主旨理解**：单选题（深度分析客户异议的核心驱动力）。
     - **弦外之音 (Read between the lines)**：深度剖析说话人委婉表达背后的真实意图与跨文化潜台词。
   - **智能即时批改与线索定位**：提交答案后即刻智能核对，并在听力原文 (Transcript) 中自动闪烁定位关键线索句，解析认知偏差。
   - **多口音多语速 TTS**：原生支持美音 (US)、英音 (UK)、印度腔 (IN)、日本腔 (JP)、澳洲音 (AU) 及多元欧洲口音。

2. **每日 10-20 分钟精练与语料库 (Daily Corpus & Immersion Hub)**
   - **商务英语经典 900 句 (Business 900)**：按场景分类（破冰寒暄、敏捷站会、排期防守、价格谈判、危机公关、高管战略），支持按场景检索与收藏。
   - **Gemini 每日推荐 TED 商业演讲**：精选全球商业、管理与科技领袖演讲切片（Simon Sinek 黄金圈法则、Ray Dalio 极度透明、Satya Nadella 微软文化等），支持双语字幕与商业思维洞察，更可由 Gemini 动态推荐生成最新演讲切片。
   - **播放 ⇄ 复读 ⇄ 复盘对比三步闭环**：
     - **原音播放**：多国口音（美/英/印）与 0.8x-1.2x 语速调节。
     - **单句复读模式**：支持连续循环 2遍、3遍或无限复读，自动留白跟读时间。
     - **开麦录音与即时复盘对比**：用户录制发音后，系统即刻生成**【标准原声 vs 我的发音】逐词对比报告**，标绿读对单词，标红吃字漏读，给出音准流利度与外企教练点拨。
   - **每日 10-20 分钟计时与打卡**：顶部动态计时圈，训练达标自动触发彩带并记录连续天数。

3. **动态场景模拟引擎 (AI Roleplay & Meeting Simulation)**
   - **自定义会议人设与基调**：苛刻挑剔的北美 VP、语速极快的印度技术主管、目标导向的英国 PM、审视型华尔街董事等。
   - **低延迟多模态交互**：基于浏览器的语音识别 (ASR) 与静音检测 (Silence Detection)，实现自然轮流发言；支持随时**中途打断 (Interrupt)** 与即兴反驳。
   - **企业级业务语料库注入**：支持一键上传或贴入真实业务 PRD、邮件往来、会议纪要，AI 依此生成专属情境对练。

3. **四维实时评分与反馈系统 (Core Evaluation Unit)**
   - **发音与流利度**：重音位置、辅音爆破、连读弱读指导与错音提示。
   - **语法与词汇 (Chinglish to Native)**：彻底告别中式逐字直译，精准提供母语级职场表达替换。
   - **商务语用与得体度**：评估委婉礼仪指数，将生硬命令句转化为符合跨国协作的高情商话术。
   - **任务达成率**：科学评定是否成功化解异议、争取到排期缓冲或守住谈判底线。

4. **“教练式”复盘与个人知识图谱 (Personal Knowledge Graph)**
   - **AI 三级进阶改写建议 (Paraphrasing Engine)**：
     - 极简清晰版 (Concise & Clear)
     - 高情商委婉版 (Diplomatic & Tactful)
     - 投行/高管专业版 (Executive & Polished)
   - **弱点追踪看板 (Weakness Tracker)**：自动收录常错词汇、高发 Chinglish 漏洞、听不懂的特定口音盲区，支持一键专项复训。

## 🚀 进阶式学习路径 (L1 ~ L4)

| 阶段 | 对应等级 | 核心目标 | 听力素材特征 | 口语练习形式 |
| :--- | :--- | :--- | :--- | :--- |
| **L1** | **破冰与基础构建**<br>*(0基础 - A2)* | 克服开口恐惧，掌握高频职场词汇与数字/排期确认 | 慢速、清晰的标准美音/英音（HR入职引导、简单寒暄） | 核心词汇跟读、高频句型复述、情景填空朗读 |
| **L2** | **标准职场沟通**<br>*(B1 - B2)* | 应对日常工作汇报、站会发言与跨部门协作防守 | 正常语速单/双人对话（Daily Stand-up、API Blocker、工单支持） | 简答对话、中文大意即时转换为地道职场英文 |
| **L3** | **复杂业务与多元口音**<br>*(B2 - C1)* | 适应全球多元口音，应对高压谈判与专业汇报 | 印度腔、日本腔、欧洲口音（供应商 SLA 议价、处理紧急故障投诉） | 2分钟主题简报、针对刁钻反问的沉着应对 |
| **L4** | **高阶会议与动态模拟**<br>*(C1 - C2)* | 纯英文高管控场，处理突发危机与信息高密度多方会议 | 极速美英混合、术语密集、多人插话与抢话（财报电话会、战略闭门答辩） | 1v1 或 1vN 沉浸式模拟，动态追问、即兴打断与反驳 |

## 🛠️ 技术架构

- **前端框架**：React 19 (`react` + `react-dom`)
- **语言与构建**：TypeScript 5.7 + Vite 6
- **样式方案**：Tailwind CSS + Tailwind Merge + Lucide React 图标
- **AI 大模型**：Google Gemini 多模态 API (`@google/generative-ai`，支持 Gemini 1.5 Flash / Pro / 2.0 Flash)
- **语音技术**：
  - **TTS 语音合成**：Web Speech Synthesis API，针对 US/UK/IN/JP 提供音高调谐与速率仿生补偿。
  - **ASR 实时语音识别**：Web Speech Recognition API，支持流式转写与自动静音检测截断。
- **本地存储**：LocalStorage，API Key 安全留存本地，且内置**智能演示离线兜底模式**（零配置即可秒开体验）。

## 💻 本地运行与开发

### 1. 安装依赖
```bash
npm install
```

### 2. 启动本地开发服务
```bash
npm run dev
```
在浏览器中打开控制台输出的地址（通常为 `http://localhost:5173`）。

### 3. 构建生产版本
```bash
npm run build
```

## 🌐 发布到 GitHub 并开启浏览器访问

### 步骤 1：在 GitHub 上创建新仓库
1. 登录 [GitHub](https://github.com/)，点击右上角 **New repository**。
2. 仓库名称填写例如：`bizpulse-ai` 或 `business-english`。
3. 选择 **Public**，不要勾选 "Add a README"（本地已有完整代码），点击 **Create repository**。

### 步骤 2：推送到 GitHub
在当前项目根目录下执行：
```bash
git remote add origin https://github.com/kevinxueyf/Business-English-Practice.git
git branch -M main
git push -u origin main
```

### 步骤 3：开启 GitHub Pages 免费在线访问
1. 进入 GitHub 仓库页面：`https://github.com/kevinxueyf/Business-English-Practice`
2. 点击 **Settings** -> **Pages**。
3. 在 **Build and deployment** -> **Source** 中选择 **GitHub Actions**。
4. 项目已内置了 `.github/workflows/deploy.yml`，每次推送代码后，GitHub 会自动完成构建并生成专属公开网址：
   👉 **`https://kevinxueyf.github.io/Business-English-Practice/`**，在手机或电脑浏览器中直接打开即可使用！

## 🔑 Gemini API Key 配置说明
1. 点击应用右上角的 **“Gemini API 配置”** 按钮。
2. 前往 [Google AI Studio](https://aistudio.google.com/app/apikey) 免费申请 API Key。
